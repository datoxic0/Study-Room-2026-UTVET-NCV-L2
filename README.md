## What it does

| View | Purpose |
|---|---|
| **Desk** | Countdown to next exam, daily study plan (persisted), exam runway, AI study buddy (websim), 25-min focus timer |
| **Past papers** | **Verified** question-paper + memorandum links for all 7 of your subjects, matched to your timetable, plus the official source registry (DBE, Thutong, DHET/NOLS) and per-subject deep search (DuckDuckGo / Bing / Google) |
| **Notebooks** | Your **17 NotebookLM links with real titles** (auth-wall + authenticated fetch both documented) + a **local, searchable library** of all 17 exports with sha256 integrity per file |
| **Study guides** | **7 subject study guides** built from the 76-source NotebookLM capture set: topic maps, mark-award culture, worked procedures, self-check quizzes — every claim sha-verified against `manifest.json` by the test suite; empty-capture subjects (English FAL) get an honest gap plan, never invented syllabus |
| **Papers workroom** (in Study guides) | **30 captured question papers & memoranda**, attempt-first reader: answer rows stay hidden until you reveal them; 61 verbatim answers in hand (38 memo rows + 23 solved-set rows) plus 6 worked solution blocks, 11 entries honestly labelled summary-only, 4 QP/memo pairs cross-link, every entry shows its capture file + sha256 |

- Every external link carries a verification date (`2026-09-30`) and class: `official`, `community`, `unreachable`.
- Research lives in `research/`: search log (J9), captures with **sha256** (J2), and `evidence.json` gated by
  `corroborate.py --strict --require-hash` â†’ **PASS, 7/7 claims CORROBORATED** (17/17 evidence hash-provenanced).
- Links that failed from the build network (`nols.gov.za`, `utvet.co.za`) are shown **flagged**, not hidden.
- NotebookLM: unauthenticated fetches are **always** redirected to sign-in (measured, captured). With a signed-in Edge session via CDP, **17/17 notebooks were fetched and ingested** (see `research/02_NOTEBOOKLM_ACCESS_AUDIT.md`).

## Commands

```bash
npm run check            # lint + unit tests incl. guide provenance (must exit 0)
npm run lint             # bespoke validator: syntax, DOM ids, URL registry, data sanity, Angel terminology
npm run test             # node:test suite
npm run index-notebooks  # rebuild data/notebooks/index.json from exports
npm run ingest-sources   # rebuild data/notebooks/*.sources.txt from hashed source captures
npm run extract-papers   # regenerate js/data/paper_shelf.js from the 17 hashed captures (deterministic)
npm run serve            # local server at http://localhost:8080
```
